> **Zero-Bloat PDF Compressor & Metadata Sanitizer CLI.** Compress heavy PDF documents for campus portals, journal submissions, and job applications, while wiping sensitive tracking metadata (Author names, GPS, and creation software).

---

## 🚀 Quick Install

```bash
pip install pdfslim
```

---

## 🖥️ Usage

### 1. Compress Heavy PDF
```bash
pdfslim compress heavy_report.pdf -o report_compressed.pdf
```

### 2. Inspect PDF Size & Page Count
```bash
pdfslim info document.pdf
```
